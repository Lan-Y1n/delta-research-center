# 德尔塔研究中心 · 需求规格（SPEC）

> 本文件是交给 Codex 的唯一需求来源。任何与本文件冲突的“常识补充”都不要做——**尤其不要编造人物经历、学术成果、真实联系方式**。
> 站点是**虚构科研机构**的官方网站，用于个人站演示/作品展示，不对应任何真实机构。

---

## 0. 一句话目标

用 React + TypeScript + Tailwind 构建一个**多页面、真实可交互**的未来科研机构官网，视觉基线为「纯黑 + 超大字号 + 大圆角玻璃 + 柔和辉光」的 Apple 式极简风格（见 `demo/d.html`），并交付一套可在 Debian 虚拟机上用 `docker compose` 一键部署的工程。

## 3. 数据模型（必须独立数据文件、交叉引用、禁止复制粘贴文案）

建议：`src/data/leaders.ts`、`institutes.ts`、`projects.ts`、`contact.ts`、`site.ts`，统一 `src/data/types.ts`。

```ts
type Leader = {
  slug: string;            // lanyin
  no: string;              // "01"
  name: string;            // 澜因 / 数据删除
  nameEn: string;          // LANYIN / DATA EXPUNGED
  glyph: string;           // 单字，用于视觉水印：澜 / 慧 / 质 …（redacted 用 "?"）
  role: string;            // 物理研究院负责人
  roleEn: string;
  instituteSlug: string;   // 关联 INSTITUTES
  hue: number;             // 0-360，用于人物视觉主色调
  redacted?: boolean;      // true 时姓名显示为「数据删除」，禁用编造内容
  portrait?: string;       // 9:16 图片路径，缺省用占位视觉
  bio?: string;            // 未提供 → 不填，页面显示占位块
  fields?: string[];       // 专业领域（未提供 → 空数组，显示占位）
  directions?: string[];
  career?: string[];
  achievements?: string[];
  projects?: string[];     // 引用 PROJECTS.code
};

type Institute = {
  slug: string; no: string;
  name: string; nameEn: string;   // 物理研究院 / Institute of Physics
  code: string;                   // DRC-PHY
  tagline: string;                // 物质 · 能量 · 测量
  kind: 'institute' | 'force';    // armed-forces 为 'force'
  leaderSlug: string | null;      // 武装力量为 null
  intro: string[];                // 占位可换
  directions: { title: string; desc: string }[];
  facilities: { name: string; desc: string }[];
  units?: { name: string; desc: string }[];      // 仅 force
  equipment?: { name: string; desc: string }[];  // 仅 force
  duties?: { name: string; desc: string }[];     // 仅 force
};

type Project = {
  code: string; name: string;
  instituteSlug: string;
  desc: string;
  progress: number;   // 0-100
  status: 'planning' | 'active' | 'completed' | 'hold';
  statusLabel: { cn: string; en: string };  // 筹备中/进行中/已完成/暂停
};

type Contact = {
  email: string; phone: string; location: string;
  socials: { name: string; handle: string; url: string }[];
};
```

**固定数据（不得改动）**

- 负责人 5 人：`澜因`(物理)、`慧矢`(生物)、化学研究院负责人姓名必须原样显示 **`数据删除`**、数学研究院负责人姓名必须原样显示 **`数据删除`**、`质湮`(哲学)。
- 武装力量**不设负责人**、**不进入首页轮播**、不得绑定其他院所负责人。
- 示例项目 6 条（可改内容，但结构保留）：`DRC-PHY-2401 亚稳态量子相干阵列 12% 筹备中`、`DRC-BIO-2402 自组织细胞图谱 64% 进行中`、`DRC-CHM-2403 低温催化路径筛选 38% 进行中`、`DRC-MTH-2404 高维拓扑不变量计算框架 100% 已完成`、`DRC-PHL-2405 意识边界的形式化描述 21% 暂停`、`DRC-AFR-2406 分布式感知节点组网 47% 进行中`。
- 联系方式全部为**占位**：`your-name@lany1n.icu`、`+86 000 0000 0000`、4 个社交媒体占位账号（GitHub / X / Telegram / Bilibili），链接指向对应平台首页即可，不得伪造成真实账号。

## 4. 首页（纵向滚动）

### 4.1 首屏（桌面按 16:9 横向构图设计基准）

左右分栏：

- **左**：eyebrow 小字 → 中文主标题「德尔塔研究中心」（极大字号、紧凑字距、白色→冰蓝渐变）→ 英文 `DELTA RESEARCH CENTER`（大字距辅助）→ 标语 → 一段简介 → 两个按钮「探索研究领域 [01] →」「合作联络 ↗」→ 四联数据（05 研究领域 / 06 研究院所 / 06 在研项目 / 01 交叉平台）
- **右**：负责人照片轮播，**9:16 竖向构图**，同一时间**只显示一张**

轮播硬性要求：

- 5 张（顺序：澜因、慧矢、化学、数学、质湮），横向滑动切换
- 自动轮播（约 5.5s）；鼠标悬停暂停；暂停/播放按钮
- 手动左右按钮、键盘 ← →、鼠标按住拖动、移动端触控滑动
- 切换使用平滑过渡（不能用瞬时跳变）；拖拽结束不应误触发“点击跳转”
- 每张图下方/内部同步显示：编号 `01 / 05`、姓名、职务、所属院所英文名
- **点击当前展示的照片** → 该负责人所属研究院页
- 未提供真实照片时：用 CSS/SVG 生成“档案底板”（人物首字水印 + 色调 `hue` + 细网格），并保留 `<img src="/img/leaders/{slug}.jpg">` 位置与 `onError` 降级，便于以后直接替换图片

### 4.2 第二屏：在研项目

- 英文小标 `CURRENT RESEARCH PROJECTS` + 中文大标题「目前研究项目」
- 右上角必须明确标注：**示例占位数据（SAMPLE DATA）**
- 卡片 3 列（桌面）/ 1 列（移动），每卡包含：项目编号、状态徽章、项目名、所属院所、简介、进度百分比数字、可视化进度条（进入视口时平滑填充）、底部「项目详情 ↗」
- 悬停有轻微高光/抬升；点击卡片进入项目详情页
- 数据来自 `projects.ts`，改数字即可生效

### 4.3 第三屏及以后：机构介绍

- 机构简介、设施功能（低温测量 / 光学与光谱 / 计算与数据节点 等）、科研定位、组织概况
- 全部为**可替换占位文本**，每块标注「占位」
- 结尾一个 CTA 指向合作页

## 5. 六个领域页（统一结构）

1. 页头：面包屑 + 英文 eyebrow（`INSTITUTE OF PHYSICS · DRC-PHY`）+ 中文名 + 英文名 + 关键词标签 + 右上 `01 / 06`
2. 研究院简介（2 段占位）
3. 主要研究方向（3 条）
4. 研究设施与实验条件（3 项卡片）
5. 研究项目（引用该院所的 PROJECTS）
6. 负责人介绍卡（照片 + 姓名 + 职务 + **「查看负责人详情 VIEW PROFILE」按钮**）
7. 侧栏：领域编号 / 院所编码 / 负责人 / 在研项目数

武装力量（`/field/armed-forces`）特殊处理：

- 是**独立领域分区**，不是普通院所；采用独立组织介绍布局
- 必须包含：简介、组织架构、下属单位与部门（6 项）、装备与技术体系（4 项）、任务定位与职能（4 项）、相关人员（占位）
- **不得**出现负责人卡、**不得**绑定其他院所负责人，页头编号为 `06 / 06`

## 6. 负责人详情页

- 左：9:16 人物视觉（sticky），编号、返回本院所链接
- 右：姓名（超大）、英文名、职务与所属院所标签、个人简介、专业领域、研究方向、学术经历、研究成果、代表性科研项目
- **未提供的内容一律用可编辑占位块**（视觉上明显是占位，例如虚线框 + 「占位 · 待补充」），**严禁编造**
- `redacted: true` 的两位负责人：姓名固定「数据删除」，页面显示脱敏说明（人事档案已封存/数据删除），可用占位块说明“该职位信息未公开”，不得虚构姓名或经历
- 数据来自 `leaders.ts`，首页 / 院所页 / 详情页必须是**同一份数据**

## 8. 视觉规范

**色板（必须使用，落地为 CSS 变量 / Tailwind theme）**

| 用途 | 值 |
|---|---|
| 页面背景 | `#07111F`（纯黑方案可用 `#000` 作舞台底，正文面板仍在深蓝系） |
| 次级背景 | `#0B192B` |
| 面板 | `#13263B` |
| 主强调 | `#65C9F4` |
| 次强调 | `#91E5F2` |
| 辅助文字 | `#9BB4CA` |
| 主文字 | `#EAF4FC` |
| 边框 | 半透明冰蓝 `rgba(101,201,244,.14)` ~ `rgba(145,229,242,.32)` |

**风格要求**

- 未来主义 + 现代科研机构；冷色系；克制、专业、高级
- 液态玻璃 + 高斯模糊：导航 `backdrop-filter: blur()`、玻璃卡片、背景光斑、装饰层 `filter: blur()`；**模糊只作用在背景/装饰层，禁止模糊文字、照片和主要信息**
- 不支持 `backdrop-filter` 时降级为半透明纯色（用 `@supports not (backdrop-filter: blur(1px))`）
- 大圆角（卡片 20–32px）、克制的柔和辉光，避免廉价塑料感与过度发光
- 三种自选微调可选：纯黑舞台 / 抬亮一档磨砂 / 深空玻璃（参考 `demo/d.html`、`e.html`、`f.html`）

**动效（克制动效）**

- 路由切换淡入过渡（200–300ms）
- 轮播滑动、卡片悬停高光/抬升、进度条进入视口填充、下拉菜单展开收起、滚动 reveal 淡入、按钮按压反馈
- 禁止：闪烁、满屏粒子、影响文字可读性的背景特效、强制滚动
- 必须支持 `prefers-reduced-motion: reduce`（关闭大位移与自动轮播）

**响应式**

- 桌面（≥1280）/ 笔记本（1024–1280）/ 平板（768–1024）/ 手机（<768）
- 桌面优先保证 16:9 首屏构图（首屏内容在 1280×800 内完整可见，不出现上下裁切）
- 移动端：左右分栏改上下堆叠、文字不溢出、图片不变形、轮播可触控、汉堡菜单可用、玻璃效果不造成明显掉帧
